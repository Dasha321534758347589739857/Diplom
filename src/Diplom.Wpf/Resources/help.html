1. Введение

1.1. Тема

Программный комплекс для оценки последствий нештатных ситуаций на объектах шахтного типа (ПК «НС-ШТ»).

1.2. Назначение программного комплекса

Программный комплекс «НС-ШТ» предназначен для автоматизированной оценки последствий и рисков при возникновении нештатных ситуаций (в частности, взрывов газовоздушных смесей) на объектах шахтного типа. Основная задача комплекса — поддержка принятия решений в области промышленной безопасности за счет моделирования опасных факторов и прогнозирования их воздействия на персонал и объекты инфраструктуры.

1.3. Цель работы программного комплекса

Повышение безопасности работников предприятий за счёт разработки специализированного программного комплекса для прогнозирования последствий нештатных ситуаций (НС) и оценки рисков на объектах шахтного типа (коллекторы, трубопроводы, резервуары, скважины и другие объекты с ограниченным пространством).

2. Общее описание

2.1. Функциональные требования (основной функционал)

Для Пользователя:

  • Авторизация в системе
  • Ввод параметров для моделирования (выбор/задание объекта, вещества, параметров среды)
  • Задание координат эпицентра нештатной ситуации и наблюдателя
  • Расчёт и визуализация параметров взрывной волны
  • Оценка рисков для человека в точке нахождения наблюдателя
  • Выгрузка результатов в файл

Для Администратора:

  • Управление базой данных (добавление, редактирование, удаление записей)
  • Работа со справочниками: вещества, объекты, грунты, воздух
  • Управление учётными записями пользователей
  • Назначение ролей и прав доступа

2.2. Целевая аудитория

  • Инженеры по техносферной безопасности
  • Специалисты по промышленной безопасности
  • Администраторы системы
  • Научные сотрудники, занимающиеся моделированием аварийных ситуаций

3.4. Анализ результатов

3.4.1. Таблица с результатами расчёта

После завершения расчёта в соответствующей вкладке появится таблица со следующими колонками:

  • Время (t, с): Время прихода волны в точку

5.2. Установка и запуск

  1. Распакуйте дистрибутив программы в выбранную папку.
  2. Убедитесь, что на компьютере установлен .NET Framework версии 4.7.2 или выше.
  3. Для запуска программы выполните двойной клик по файлу NS_SHT.exe.
  4. При первом запуске система может запросить разрешения на доступ к сети (для проверки обновлений) и файловой системе (для работы с базой данных).
Примечание: Для нормальной работы программы требуются права на запись в папку с программой (или в папку пользователя) для создания и обновления файла базы данных.

6. Приложения (глоссарий)

6.1. Основные термины и определения

Термин Определение
Нештатная ситуация (НС) Совокупность условий и обстоятельств при использовании технических систем, отличающихся от предусмотренных проектами, нормами и регламентами и ведущих к возникновению опасных состояний в технических системах.
Объект шахтного типа Объект с ограниченным замкнутым пространством, характеризующийся большой протяжённостью и малой площадью горизонтального сечения (коллекторы, трубопроводы, резервуары, скважины).
Избыточное давление (ΔP) Давление, превышающее атмосферное, во фронте ударной волны. Измеряется в килопаскалях (кПа). Основной поражающий фактор при взрыве.
Импульс фазы сжатия (I) Интеграл избыточного давления по времени действия фазы сжатия. Измеряется в кг·м/с. Характеризует ударное воздействие волны.
Пробит-функция (Pr) Вероятностная функция, используемая для оценки вероятности поражения людей при воздействии опасных факторов. В программе рассчитываются Pr3 (потеря ориентации), Pr4 (разрыв барабанных перепонок), Pr5 (отброс ударной волной).
Загромождённость пространства Степень заполнения объекта оборудованием, конструкциями и другими предметами. Классифицируется от 1 (максимальная загромождённость) до 4 (свободное пространство). Влияет на режим взрывного превращения и скорость фронта пламени.

6.2. Используемые математические модели (кратко)

В основе расчётов программного комплекса лежат методики, описанные в следующих нормативных документах и источниках:

  • Руководство по безопасности «Методика оценки последствий аварийных взрывов топливно-воздушных смесей» (2015)
  • Приказ МЧС РФ от 10.07.2009 N 404 «Методика определения расчетных величин пожарного риска на производственных объектах»
  • Отраслевое руководство по анализу и управлению риском (РАО «Газпром», 1996)

Расчёт включает определение приведённой массы газа, эффективного энергозапаса ТВС, безразмерного давления и импульса, а также оценку вероятности поражения людей через пробит-функции.
